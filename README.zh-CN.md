# EasyEDA PCB MCP 3.0.1

优先通过 MCP 完成常见 PCB 操作，AI 决定布局、显式路径和分析时机。默认21工具，普通编辑直接传 operations，使用位号、引脚端点和层名。编辑坐标、总览/引脚数据、坐标拾取、SVG区域和贴片坐标导出均默认 mil；需要毫米时显式传 `units: "mm"` 或 `unit: "mm"`。不需要 guard、expected、prepare 或固定小批。

封装位置与朝向、整体变换、对齐分布、径向排列、完整线路和圆弧、过孔、孔槽、独立焊盘、板框、铜区、区域、文字、修改删除、位号显示、元件插入和铜层数。传输分片在内部处理。

读取总览提供器件、封装、尺寸来源、真实焊盘网络与不同朝向映射。结果较大时保存完整数据，使用 resultId 分页读取。整体/局部 SVG 可显示引脚网络，底面视图正确镜像；辅助标签不写入 PCB 丝印。

原生错误、部分成功、未知状态、保存和图片失败分别报告。检查工具按需返回事实，不对编辑作设计审批。单一 PCB 可省略目标，多目标用明确文档 UUID。不会自动寻路或改变用户明确路径。

安装：Node.js >=22，npm ci 后 npm test、npm run smoke，再启动 node src/server.mjs。仅注册默认服务，旧配置保留用于历史兼容，不参与日常选择。

目前验证包括自动化模拟编辑与客户端4.1.60真实只读总览、SVG，不代表所有写操作完成实机验证。测试副本与生产 PCB 明确分开，普通封装缺口应补进 MCP，不以手写 API 替代交付。
